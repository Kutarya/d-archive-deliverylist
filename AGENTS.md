# Project language policy

- The current requirement is selectable English, Czech and Turkish, superseding the earlier English-only requirement.
- English is the default interface and output language.
- Settings must let users choose interface and output languages independently. Persist both choices on the device.
- Apply the interface choice to navigation, fields, settings, statuses, validation messages, errors, dialogs and accessibility labels.
- Apply the output choice to generated Excel worksheet names, headings, document types, PDF/image labels, dates, number formatting and generated filenames.
- Keep catalog translations complete for all three languages. Test combinations where interface and output languages differ.
- Preserve existing archives, backups, application identity and Android signing keys. Continue reading legacy workbooks in all supported languages.
- Preserve source photos, identifiers, company/person names and user-entered document content. Changing language changes generated presentation and must not silently rewrite source records.
- Do not claim current release acceptance using evidence from an earlier version.
